DB SCHEMA SUMMARY (for reference):
- warungs: id(text pk, cuid), nama(text), created_at
- menu_items: id(text pk, cuid), warung_id(fk->warungs), nama_item(text), harga(integer, rupiah), created_at. Unique index on (warung_id, nama_item).
- sessions: id(text pk, cuid), warung_id(fk->warungs), tanggal(date), status(enum 'open'|'closed'), nama_penagih(text,nullable), nama_bank(text,nullable), no_rekening(text,nullable), biaya_tambahan(integer,default 0), closed_at(timestamp,nullable), created_at
- orders: id(text pk, cuid), session_id(fk->sessions), nama_pemesan(text), created_at. Unique index on (session_id, nama_pemesan) — one order per name per session.
- order_items: id(text pk, cuid), order_id(fk->orders), menu_item_id(fk->menu_items), qty(integer, default 1). Unique index on (order_id, menu_item_id).

IMPORTS NOTE: Use `import { db, schema } from "@/db"` for the db instance. Use `import { queries } from "@/db/queries"` — WAIT, queries.ts exports individual functions, not a namespace. === API ROUTES (7 files) ===

1. src/app/api/warungs/route.ts
   - GET: return all warungs (call getAllWarungs), as JSON.
   - POST: create warung. Body: { nama: string }. Validate nama not empty. Insert into warungs table, return the created warung as JSON with status 201.

2. src/app/api/warungs/[id]/route.ts
   - GET: return warung by id (getWarungById) + its menu items (getMenuItemsByWarung). Return { warung, menuItems }.
   - PUT: update warung nama. Body: { nama: string }. Return updated warung.
   - DELETE: delete warung by id. Use db.delete(warungs).where(eq(warungs.id, id)). Return 200.

3. src/app/api/menu-items/route.ts
   - POST: create menu item. Body: { warungId, namaItem, harga }. Validate all fields. Insert into menu_items. Return created item with 201.

4. src/app/api/menu-items/[id]/route.ts
   - PUT: update menu item. Body: { namaItem?, harga? }. Update only provided fields. Return updated item.
   - DELETE: delete menu item by id. Return 200.

5. src/app/api/sessions/route.ts
   - GET: return all sessions with warung data (call getAllSessions). As JSON.
   - POST: create session. Body: { warungId, tanggal?, namaPenagih?, namaBank?, noRekening?, biayaTambahan? }. tanggal defaults to today. status defaults to 'open'. biayaTambahan defaults to 0. Insert and return created session with 201.

6. src/app/api/sessions/[id]/route.ts
   - GET: return session by id (getSessionById) + orders (getOrdersBySession). Return { ...sessionRow, orders }.
   - PUT: update session. Body can include: status (to close/open), namaPenagih, namaBank, noRekening, biayaTambahan. If status is being set to 'closed', also set closedAt to now. If status set to 'open', clear closedAt. Return updated session.

7. src/app/api/orders/route.ts
   - POST: submit an order. Body: { sessionId, namaPemesan, items: [{ menuItemId, qty }] }.
     - Validate sessionId, namaPemesan, and items not empty.
     - Check if namaPemesan already has an order in this session (query orders table). If exists, return 409 with { error: "Nama ini sudah memesan di sesi ini" }.
     - Insert into orders table (sessionId, namaPemesan).
     - Insert all order_items for that order.
     - Return created order with items, status 201.
   - Handle the unique constraint violation as backup (catch error, if it's a unique violation on session_nama_idx, return 409).

IMPORTANT CONSTRAINTS:
- Use Next.js App Router conventions. Server components by default, "use client" only when needed (forms, interactivity).
- Use `import { NextResponse } from "next/server"` for API responses.
- Use `import { eq } from "drizzle-orm"` and `import { db } from "@/db"` and `import { warungs, menuItems, sessions, orders, orderItems } from "@/db/schema"` in API routes.
- Use the query functions from "@/db/queries" where available (they already handle joins).
- For mutations (INSERT/UPDATE/DELETE) in API routes, use db directly: db.insert(table).values({...}).returning(), db.update(table).set({...}).where(eq(...)), db.delete(table).where(eq(...)).
- All rupiah formatting: use formatRupiah() from "@/lib/utils".
- All dates: use formatDateID() from "@/lib/utils".
- Tailwind v4 classes (no config file needed, uses @import "tailwindcss").
- Mobile-first design, max-w-3xl container, orange accent color (orange-600).
- No external UI libraries — just Tailwind + raw HTML elements.
- TypeScript: use proper types from schema exports where possible.
- For client components that mutate data, use `const router = useRouter(); router.refresh()` after fetch.
- For form submissions in client components: use fetch() to call the API routes, not server actions.
- Remember: Drizzle ORM with node-postgres. The `db` instance is already configured with snake_case casing.
- When inserting into menu_items table, the column names in JS are camelCase (warungId, namaItem, harga) because drizzle maps them to snake_case automatically.
- Same for sessions (warungId, namaPenagih, namaBank, noRekening, biayaTambahan) and orders (sessionId, namaPemesan) and order_items (orderId, menuItemId).
